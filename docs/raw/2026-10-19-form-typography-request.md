# Form typography request

The owner asked to review the makers form because it has too many font sizes and
treatments. They prefer the typography in the hero and the section that follows
it, and asked to normalize form typography without diverging much from those
styles. Smaller supporting elements should remain the same size and use brown
instead of black to read more quietly. The owner also said the brown token can
be slightly lighter.

Source: user instruction in the project conversation, 2026-10-19.
