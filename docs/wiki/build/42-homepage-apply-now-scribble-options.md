# Homepage Apply now scribble options

The owner supplied a complete hand-drawn “Apply now!” oval and down-right
arrow, asked for it to replace the status text and prior cue, and requested
options for site colors. [Request](../../raw/2026-10-19-homepage-apply-now-scribble-request.md)

The one-page PDF contains vector paths for the lettering, oval, and arrow.
Three recolored SVG backgrounds preserve those paths while dropping the large
empty page canvas. The comparison shows the same proposed size and placement
for each treatment. [Review page](../../../.lavish/homepage-apply-now-options.html)

| Option | Treatment | Direction |
| --- | --- | --- |
| A | Ink lettering with Marker Red oval and arrow | Selected and implemented: clear writing with a red action mark. |
| B | All Marker Red | Stronger, single-color callout. |
| C | All Ink | Quietest and highest-contrast treatment. |

The selected SVG replaces the status copy and prior arrows as one complete
link under the homepage introduction. It links to `#take-part`, where both
application routes begin. The artwork appears only while applications are
open; other edition states retain the dynamic status wording. The link has an
accessible name and visible keyboard focus treatment. The running homepage
was reviewed after implementation.
